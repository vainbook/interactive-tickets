# 互動門票

兩個人用同一支手機，各自滑同一張「門票」：右滑想要、左滑不要、下滑不確定。兩人都想要的事，就是你們的共識，會收進票夾。

**線上試玩：** https://vainbook.github.io/interactive-tickets/

示範影片：[demo.mp4](demo.mp4)

## 玩法

- **三種情境**：認識（不限關係，從喜好認識彼此）、約會（讓關係升溫）、限制級（18+）
- **三種玩法**：同時翻牌（面對面，上半畫面倒過來給對方看）、各滑各的（同一組題目、順序不同）、輪流滑（傳手機，看不到彼此的選擇）
- **集點卡**：集滿 8 個共識過關，作廢 3 張散場；每 5 題輪流選一次「下一站」方向
- **票夾**：說好的事可以排日期、加到 Google 日曆，做完蓋上「已使用」並留一句回憶
- 支援中文、English、日本語、한국어，依手機語言自動切換，題目都在地化改寫；可設第二語言（對面玩家用另一種語言，或題目下方加註）
- 題庫約 1000 題，8 種情境各有自己的票種（發票、電影票、登機證、車票、樂園票、演唱會票、明信片、房卡）

## 技術

單一 HTML 檔，不需要安裝或建置，直接用瀏覽器打開 `index.html` 就能玩。紀錄只存在這台裝置的瀏覽器（localStorage），不會上傳到任何伺服器。

限制級情境不會預設開啟，需要在首頁手動選擇；請確認遊玩者皆已成年。
